# Pixel Poker

A pixel-art poker trainer built with **Lua**, **LÖVE2D**, and **Aseprite**.

## Overview

`Pixel Poker is a personal project exploring poker strategy, game development, and pixel-art design.

The goal is to build an interactive environment for practicing poker fundamentals, evaluating hands, and improving decision-making.

## Planned Features

- Interactive playing cards and poker table
- Deck generation and shuffling
- Poker hand evaluation
- Texas Hold'em gameplay
- Pot odds and equity calculations
- Interactive poker training scenarios

## Tech Stack

- **Lua** — Game logic
- **LÖVE2D** — 2D game framework
- **Aseprite** — Pixel art and sprites

## Running

Install [LÖVE2D](https://love2d.org/), clone the repository, and run:

```bash
love .
```
